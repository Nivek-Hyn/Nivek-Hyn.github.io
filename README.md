# nivek-hyn.github.io

The portfolio of Kevin Huynh, software developer and Epitech student in Marseille: **[nivek-hyn.github.io](https://nivek-hyn.github.io/)**

- **The site** presents my projects (R-Type, Sensai, Corewar, Wolf3D, 42sh, my_pgp...), my path and my skills, in English and French, readable without the 3D.
- **The 3D world** ([world.html](https://nivek-hyn.github.io/world.html)) is a small game that runs in the browser: a city of robots inspired by computing, where developer tools become equipment.

**TypeScript · Vite · Three.js (WebGPU with WebGL fallback) · Rapier physics · GitHub Actions**

The 3D world starts from a fork of the open-source engine of [Bruno Simon's portfolio](https://github.com/brunosimon/folio-2025) (MIT licence), which brings the rendering base and the physics setup; the city, the robot, the tools, the enemies, the interface and the progression are this project's own. Built with AI coding agents (Claude Code), with the design, direction, review and deployment done by me.

This repository only holds the built site: it is generated and deployed automatically from a private source repository, so changes made here are overwritten.
